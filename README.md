
# Power BI + MySQL Data Analytics Project

## Project Overview
This project demonstrates an end-to-end data analytics workflow using MySQL and Microsoft Power BI.

The objective is to connect a relational database with Power BI, explore the available data, and develop meaningful insights through data visualization.

## Tools & Technologies
- MySQL
- MySQL Workbench
- Microsoft Power BI
- SQL

## Project Workflow
1. Connected MySQL database to Power BI.
2. Imported data from MySQL.
3. Explored and understood the dataset.
4. Prepared data for analysis.
5. Developed an interactive Power BI dashboard.
6. Identified meaningful trends and insights.

## Repository Structure
- `SQL/` – SQL queries used in the project.
- `Screenshots/` – Dashboard screenshots.
- `.pbix` – Power BI dashboard file.

## Key Learnings
- Connecting MySQL with Power BI.
- Working with relational data.
- Writing and understanding SQL queries.
- Data preparation and visualization.
- Translating data into actionable insights.
